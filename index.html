Mini Banking Data Platform

October 2026 · Data Engineering

Data Engineer / Developer — solo: design, development, testing, and documentation

An end-to-end data platform simulating a banking data stack on synthetic data only. A Python ETL pipeline loads from PostgreSQL (core banking), MySQL (mobile banking), and MongoDB (activity logs) into a PostgreSQL warehouse built on a star schema, with SCD Type 2, incremental and idempotent loading, audit logging, and data quality checks with source reconciliation. The warehouse is served through a read-only Spring Boot REST API — including a 360-degree customer profile — a Metabase semantic layer, and Trino for cross-source data virtualization, with the pipeline orchestrated by Apache Airflow and the whole stack running on Docker Compose, backed by unit tests and GitHub Actions CI.
